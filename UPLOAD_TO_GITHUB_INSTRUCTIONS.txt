HOW TO UPDATE GITHUB
1. Open the GitHub repository used by soundhealingwithnishi.com.
2. Open the repository root, where index.html is stored.
3. Click Add file, then Upload files.
4. Drag all HTML files from this package into the upload area.
5. GitHub will show that existing files are being replaced.
6. In the commit message, enter:
   Remove completed July 10 event
7. Click Commit changes.
8. Wait for GitHub Pages to deploy.
9. Open the website in a private/incognito window and test:
   - Homepage top ribbon
   - Homepage navigation
   - Homepage around the Summer Series and reviews sections
   - Booking page
   - Gallery
   - Blog and article pages
   - https://soundhealingwithnishi.com/event-art-sound-bath.html
     This old address should redirect to the homepage.
